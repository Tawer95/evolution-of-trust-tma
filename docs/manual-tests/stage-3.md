# Stage 3 — Ручная проверка: сохранение прогресса (CloudStorage)

## Предусловия
- `webapp/` (Stage 3) задеплоен на HTTPS; бот запущен; Telegram-клиент с Bot API ≥ 6.9.

## Сценарии
1. **Save + Resume:** открой Mini App → пройди вперёд до слайда N → закрой Mini App → открой снова → оверлей «Продолжить с того места? [Продолжить] [Сначала]».
   - «Продолжить» → попадаешь на слайд N.
   - (отдельный заход) «Сначала» → splash; сохранение очищено (следующий заход без оверлея, если не прогрессировал).
2. **Язык сохраняется:** переключи RU/EN → закрой → открой → язык тот, что выбрал.
3. **Splash не триггерит оверлей:** свежий старт без прогресса → оверлея нет.
4. **Оверлей под тему:** читаем в светлой и тёмной теме (фон/кнопки по `--tg-theme-*`).
5. **Регресс вне Telegram:** в обычном браузере — оверлея нет, игра как обычно, без ошибок в консоли.
6. **Старый клиент (<6.9):** save/restore не работают (no-op), игра играется.

## Чек-лист
- [ ] прогресс сохраняется → «Продолжить» ведёт на нужный слайд
- [ ] «Сначала» → splash + очистка сохранения
- [ ] язык сохраняется между сессиями
- [ ] свежий старт без оверлея
- [ ] оверлей читаем в обеих темах
- [ ] вне Telegram — без ошибок, оверлея нет (регресс)
