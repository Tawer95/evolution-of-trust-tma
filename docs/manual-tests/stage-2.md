# Stage 2 — Ручная проверка: RU/EN + тема + хаптика + viewport-fit

## Предусловия
- `webapp/` (с правками Stage 2) задеплоен на HTTPS (Netlify); `WEBAPP_URL` в `.env`; бот запущен.
- Тест в реальном Telegram: **desktop + mobile**, **светлая И тёмная** тема, оба языка.

## Сценарии
1. **Viewport-fit (главное):** открыть Mini App на мобиле → splash и слайды **вписаны** в экран, НЕ обрезаны по краям (заголовок «THE EVOLUTION OF TRUST» виден целиком). По краям — поля (letterbox), не обрезка.
2. **Тап-точность после scale (риск pre-mortem #2):** нажать PLAY; кнопки Cooperate/Cheat (слайд one-off); **слайдеры** turns/noise (песочница, слайды distrust/noise) — попадание точное, ползунок тянется куда нужно.
3. **RU/EN:** тумблер в футере рядом со звуком → переключает весь текст на слайдах 0/3/7 без перезагрузки; персонажи (credits, слайд 9) тоже; дефолт соответствует языку Telegram-аккаунта.
4. **Тема:** переключить тему Telegram (светлая/тёмная) → рамка/футер/тумблер/метка звука перекрашиваются и читаемы; **игра остаётся на белом фоне** (рисунки видны). В **светлой** теме метки «ON/OFF» звука видны.
5. **Хаптика:** тап по кнопке → лёгкая вибрация; конец раунда (iterated) → notification-вибра; тап по пустому фону слайда — **без** вибрации.
6. **Регресс:** игра проходится как в Stage 1 — звук, листание, симуляции PD/Iterated/Tournament/Sandbox.
7. **Desktop:** в Telegram Desktop игра не апскейлится сверх 1× (как оригинал), не обрезана.

## Регресс (не сломалось)
- В обычном браузере (вне Telegram) игра грузится и играется; тумблер RU/EN работает (тема — дефолтная белая).

## Чек-лист
- [ ] нет обрезки по краям (mobile + desktop)
- [ ] тап и слайдеры точные после масштабирования
- [ ] RU/EN переключает весь текст; дефолт по языку Telegram
- [ ] тёмная + светлая тема: рамка themed, игра белая, метки звука читаемы
- [ ] хаптика только на кнопках + на конце раунда
- [ ] регресс прохождения игры ок
